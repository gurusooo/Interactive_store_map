# Interactive_store_map
## О проекте
Yummies' Cart - это прогрессивное веб-приложение для построения оптимального маршрута по залу на основе списка покупок, просмотра каталога товаров и получения подробной информации о товаре, включая его расположение в магазине. 

## Основной стек технологий

- React 19
- TypeScript
- Vite
- Zustand
- Chakra UI
- Supabase
- CSS Modules
- MapLibre GL / React Map GL
- React Router DOM
- vite-plugin-pwa

## Запуск проекта

```bash
npm install
npm run dev
```

Если возникают проблемы из-за зависимостей или различий в версиях, автор рекомендует запускать проект с флагом `--force`:

```bash
npm run dev -- --force
```

Для production-сборки:

```bash
npm run build -- --force
npm run preview
```

## Важно!

- В репозитории не хранятся ключи Supabase. Для локального запуска нужно создать `.env` файл и добавить туда свои переменные окружения;
- Приложение поддерживает PWA и может работать в установленном режиме, но для полного доступа ко всем особенностям PWA необходимо открыть chrome://flags/#allow-insecure-localhost и включить опцию;
- Для получения уведомлений о следующем собираемом товаре необходимо разрешить показ уведомлений во всплывающем окошке.
